集合 Set

一群不重複元素的無序聚集

集合是數學中最基本的概念之一。一個集合就是把一些東西放在一起，這些東西叫做元素（element）。

A = {1, 2, 3, 4, 5}

元素屬於集合用 ∈ 表示，不屬於用 ∉ 表示：

3 ∈ A   ✓     6 ∉ A   ✓

集合的特性：無序性（{1,2,3} = {3,1,2}）、互異性（元素不重複）、確定性（任何物件要嘛屬於、要嘛不屬於）。

空集合 ∅：不含任何元素的集合。∅ 是所有集合的子集。

全集 U：討論範圍內所有元素的集合（通常是一個矩形框）。

子集 ⊆ Subset

A 的每個元素都在 B 中

若集合 A 的每個元素都是集合 B 的元素，則 A 是 B 的子集，記作 A ⊆ B。

A ⊆ B ⟺ ∀x (x ∈ A → x ∈ B)
A = {1, 2}   B = {1, 2, 3, 4}
A ⊆ B   ✓ A 的每個元素都在 B 中

真子集 ⊂：A ⊂ B 表示 A ⊆ B 且 A ≠ B（B 至少多一個元素）。

聯集 A ∪ B — Union

在 A 或 B 中（或兩者皆有）的所有元素

聯集包含了兩個集合中所有的元素。只要在其中一個就算。

A ∪ B = {x | x ∈ A 或 x ∈ B}
A = {1, 2, 3}   B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}

交集 A ∩ B — Intersection

同時在 A 和 B 中的元素

交集只包含兩個集合都有的元素。

A ∩ B = {x | x ∈ A 且 x ∈ B}
A = {1, 2, 3}   B = {3, 4, 5}
A ∩ B = {3}

若 A ∩ B = ∅，則稱 A 和 B 互斥（disjoint）。

差集 A − B — Difference

在 A 但不在 B 中的元素

差集是從 A 中「扣掉」跟 B 重疊的部分。

A − B = {x | x ∈ A 且 x ∉ B}
A = {1, 2, 3}   B = {3, 4, 5}
A − B = {1, 2}

注意：A − B ≠ B − A（差集不滿足交換律）。

補集 Aʼ — Complement

全集 U 中不在 A 的所有元素

補集就是「A 以外的所有東西」，前提是有定義全集 U。

A' = U − A = {x | x ∈ U 且 x ∉ A}
U = {1, 2, 3, 4, 5}   A = {1, 2, 3}
A' = {4, 5}

重要性質：(A')' = A，A ∪ A' = U，A ∩ A' = ∅

對稱差 A △ B — Symmetric Difference

只在其中一個集合中的元素（XOR）

對稱差包含「在 A 或在 B，但不同時在兩者」的元素。就像邏輯的 XOR。

A △ B = (A − B) ∪ (B − A) = (A ∪ B) − (A ∩ B)
A = {1, 2, 3}   B = {3, 4, 5}
A △ B = {1, 2, 4, 5}

冪集 P(A) — Power Set

A 的所有子集組成的集合

冪集就是把一個集合的所有可能子集（包含空集合和自身）收集起來。

|P(A)| = 2^|A|
A = {1, 2, 3}
P(A) = {∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}}
|P(A)| = 2³ = 8 個子集

笛卡兒積 A × B — Cartesian Product

所有有序對 (a, b) 的集合

笛卡兒積是把 A 的每個元素和 B 的每個元素配對，產生所有可能的有序對。

A × B = {(a, b) | a ∈ A 且 b ∈ B}
A = {1, 2}   B = {a, b, c}
A × B = {(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)}
|A × B| = 2 × 3 = 6

注意：A × B ≠ B × A（有序對順序不同）。

重要定律 Laws

集合運算的代數性質

交換律 Commutative

A ∪ B = B ∪ A
A ∩ B = B ∩ A

結合律 Associative

(A ∪ B) ∪ C = A ∪ (B ∪ C)
(A ∩ B) ∩ C = A ∩ (B ∩ C)

分配律 Distributive

A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

德摩根定律 De Morgan's

(A ∪ B)' = A' ∩ B'
(A ∩ B)' = A' ∪ B'

恆等律 Identity

A ∪ ∅ = A
A ∩ U = A

補集律 Complement

A ∪ A' = U
A ∩ A' = ∅
(A')' = A

▲ 德摩根定律：(A ∪ B)' = A' ∩ B'
